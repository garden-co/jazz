# Current native Jazz corpus: V1 refresh

`current-native-jazz-*` is a positive corpus regenerated by the native producer.
It must reopen with current code. The separate `epoch-1-*` archives remain
unchanged as historical negative evidence and must still be rejected.

Regenerate into a fresh output directory with:

```sh
JAZZ_NATIVE_CORPUS_ROCKS_ARCHIVE_OUT=/tmp/jazz-marker-free-fixtures/rocks.tar.gz \
JAZZ_NATIVE_CORPUS_SQLITE_OUT=/tmp/jazz-marker-free-fixtures/jazz.sqlite \
JAZZ_NATIVE_CORPUS_PACK_OUT=/tmp/jazz-marker-free-fixtures/corpus.pack \
dev/t settlement_baseline_native_jazz_corpus_reopens_and_accepts_mixed_writes -- --nocapture
```

Base64-encode the pack and RocksDB archive. Compress the SQLite image with gzip
using `mtime=0`, then base64-encode it. Update the artifact digests in
`native_storage_corpus.rs` and run
`committed_native_jazz_physical_corpus_reopens_and_accepts_current_writes`.
