# BandChat

Private rooms for a band: one app in three versions.

- [`apps/nextjs-betterauth`](apps/nextjs-betterauth): Next.js and Better Auth; what BandChat demonstrates, and its test suite.
- [`apps/react-hono-betterauth`](apps/react-hono-betterauth): the same app as a Vite React single-page app with a Hono server, also deployable to Cloudflare.
- [`apps/react-hono-betterauth-e2ee`](apps/react-hono-betterauth-e2ee): the Hono app with messages, attachments and read markers end-to-end encrypted.

[`benchmarks`](benchmarks) measures BandChat's queries.
