This recipe shows how to model a simple hierarchy, inherit permissions from parent rows, and query/insert at each level.

## Schema

A simple schema with three tables linked by foreign keys. A project has tasks, and tasks have comments.

```json title="jazz.app.json"
{
  "$schema": "https://jazz.tools/schemas/jazz.app.schema.json",
  "format": 1,
  "tables": {
    "projects": {
      "columns": {
        "name": "string"
      },
      "relations": {
        "tasks": { "reverse": "tasks", "relation": "project" }
      }
    },
    "tasks": {
      "columns": {
        "title": "string",
        "done": "boolean",
        "projectId": "uuid"
      },
      "relations": {
        "project": { "rel": "projects", "column": "projectId" },
        "comments": { "reverse": "comments", "relation": "task" }
      }
    },
    "comments": {
      "columns": {
        "body": "string",
        "taskId": "uuid"
      },
      "relations": {
        "task": { "rel": "tasks", "column": "taskId" }
      }
    }
  }
}
```

## Inherited permissions

Use `allowedTo` to inherit access from the parent row. If you can read a project, you can read its tasks, and if you can read a task, you can read its comments.

```json title="jazz.permissions.json"
{
  "$schema": "https://jazz.tools/schemas/jazz.permissions.schema.json",
  "format": 1,
  "tables": {
    "projects": {
      "$comment": "Only the creator.",
      "read": "$createdBy.account = session.user",
      "insert": "true",
      "update": "$createdBy.account = session.user",
      "delete": "$createdBy.account = session.user"
    },
    "tasks": {
      "$comment": "Inherit from the project.",
      "read": "allowedTo.read(project)",
      "insert": "allowedTo.read(project)",
      "update": "allowedTo.update(project)",
      "delete": "allowedTo.delete(project)"
    },
    "comments": {
      "$comment": "Inherit from the task.",
      "read": "allowedTo.read(task)",
      "insert": "allowedTo.read(task)",
      "update": "$createdBy.account = session.user",
      "delete": "$createdBy.account = session.user"
    }
  }
}
```

The argument of `allowedTo.read(project)` is a relation name declared on the tasks table in `jazz.app.json`, here `"project": { "rel": "projects", "column": "projectId" }`. Stored column names and inferred aliases are not accepted. See [Declarative Permissions](/docs/schemas/policies) for `maxDepth` and recursive inheritance.

<Callout type="info">
  Projects use `$createdBy` instead of an explicit `owner_id` column. Jazz tracks who created each
  row automatically, so you can reference it in permissions without adding a column to your schema.
  Anyone can insert a `project`, and it will automatically be created with the appropriate
  `$createdBy` information.
</Callout>
