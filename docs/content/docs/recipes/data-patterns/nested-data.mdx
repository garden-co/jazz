This recipe shows how to model a simple hierarchy, inherit permissions from parent rows, and query/insert at each level.

## Schema

A simple schema with three tables linked by foreign keys. A project has tasks, and tasks have comments.

```ts title="schema.ts"
import { schema as s } from "jazz-tools";

export const schema = s.defineSchema({
  projects: s.table({ name: s.string() }, { tasks: s.reverse("tasks", "project") }),
  tasks: s.table(
    { title: s.string(), done: s.boolean(), projectId: s.uuid() },
    {
      project: s.rel("projects", "projectId"),
      comments: s.reverse("comments", "task"),
    },
  ),
  comments: s.table({ body: s.string(), taskId: s.uuid() }, { task: s.rel("tasks", "taskId") }),
});
```

## Inherited permissions

Use `allowedTo` to inherit access from the parent row. If you can read a project, you can read its tasks, and if you can read a task, you can read its comments.

```ts title="schema.ts"
const { definePermissions, allowedTo, session } = schema;

const createdByMe = { $createdBy: session.user };

export const permissions = definePermissions({
  // Only the creator.
  projects: {
    read: createdByMe,
    insert: true,
    update: createdByMe,
    delete: createdByMe,
  },
  // Inherit from the project.
  tasks: {
    read: (task) => allowedTo.read(task.project),
    insert: (task) => allowedTo.read(task.project),
    update: (task) => allowedTo.update(task.project),
    delete: (task) => allowedTo.delete(task.project),
  },
  // Inherit from the task.
  comments: {
    read: (comment) => allowedTo.read(comment.task),
    insert: (comment) => allowedTo.read(comment.task),
    update: createdByMe,
    delete: createdByMe,
  },
});
```

The argument of `allowedTo.read(task.project)` is a relation declared on the tasks table in `schema.ts`, here `project: s.rel("projects", "projectId")`. Stored column names and inferred aliases are not accepted. See [Declarative Permissions](/docs/schemas/policies) for `maxDepth` and recursive inheritance.

<Callout type="info">
  Projects use `$createdBy` instead of an explicit `owner_id` column. Jazz tracks who created each
  row automatically, so you can reference it in permissions without adding a column to your schema.
  Anyone can insert a `project`, and it will automatically be created with the appropriate
  `$createdBy` information.
</Callout>
