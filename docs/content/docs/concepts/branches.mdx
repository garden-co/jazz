---
title: Branches
description: Isolate application data with an environment and a user branch.
---

A Jazz branch is an isolated line of row history. The application selects it with `env` and
`userBranch` when opening `Db`. Use branches for clearly separate application contexts such as
development data, production data, and an explicit staging workspace.

```ts
const db = await createDb({
  appId: "your-app-id",
  env: "prod",
  userBranch: "staging",
  secret,
});
```

Reads and writes through that database handle operate in the selected branch. A branch is not a
filter: it is a separate history and current-row view. Choose `env: "prod"` for production and
keep test data on a different environment or user branch.

## Row history is separate

Each logical row has a stable `RowUuid` and retains an immutable history of versions within its
branch. The current-row view derives the visible result from accepted history. Branch selection
chooses the history/view; `includeDeleted()` chooses whether a query includes deleted row content.

See [How Sync Works](/docs/concepts/how-sync-works) for the relation between row versions, current
rows, fate, and replication.
