- The server is the authority: it stores data, checks policies and confirms writes
- Backends and clients subscribe to queries and get live updates
- Writes merge by default; serializable transactions when you need them
- A local replica in the client is an optional optimization (see [Local-first as a client optimization](/docs/recipes/local-first))
- More detail: [How Sync Works](/docs/concepts/how-sync-works)
