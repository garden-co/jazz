## Start with your agent

Paste this into your coding agent, or run `npm create jazz` and it prints the same brief:

```md title="Agent brief (sketch)"
Set up Jazz in this project. Follow https://jazz.tools/docs/setup and these steps:

1. Install `jazz-tools` and the Jazz agent skill.
2. Ask me the questions below. Read the linked docs before deciding, and suggest an answer.
3. Write `schema.ts` and the permission policies, then the backend routes, then the client.
4. Done when the local dev server runs, one query round-trips from backend and client, and the permission tests pass.
```

## The questions your agent should ask

- **Where does Jazz run?** Vercel, Cloudflare, or your own server. See [Deployment](/docs/setup/deployment).
- **Which backend?** Hono, Next.js route handlers, Express, or none yet. See [Backend](/docs/setup/backend/install).
- **Which client?** Thin client (small, online-only) or local-first (offline, instant UI). React or vanilla. See [Web client](/docs/setup/web-client/thin-client).
- **Who are your users?** Which auth provider, or anonymous to start. See [Auth](/docs/setup/auth/authentication).
- **What's your data?** First tables and who can read and write them. See [Schemas](/docs/schemas/defining-tables) and [Policies](/docs/schemas/policies).

## How your agent knows it's done

- A local Jazz server runs and the app connects
- A backend route reads and writes through the user-scoped client
- The frontend shows a live query that updates when the backend writes
- Permission tests cover the policies it wrote (see [Testing](/docs/tooling/testing))
