---
title: Cloudflare
description: "Run Jazz on Cloudflare: mount it in your Worker and keep the data in a Durable Object."
---

Jazz runs in your Worker. There's no Jazz server to deploy and no `jazz-tools deploy` step: the
Worker version you ship carries its schema, migrations and permissions, and a rollback with
`wrangler rollback` rolls Jazz back with it.

## Mount Jazz

```ts title="src/worker.ts"
import { Hono } from "hono";
import { jazz } from "./jazz.server";

const api = new Hono();
api.all("/jazz/*", (c) => jazz.fetch(c.req.raw));

export default api;
```

```ts title="src/jazz.server.ts"
  app,
  permissions,

```
