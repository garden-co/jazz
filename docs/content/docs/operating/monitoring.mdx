## Heap profiling

On Linux, the server samples its heap, about once per 512 KiB allocated; set
`JAZZ_HEAP_PROFILE_SAMPLE_BYTES` to change that mean, or to `0` to turn sampling off.
`GET /debug/pprof/heap` returns the sampled in-use memory as a gzipped pprof profile with function
names, for `go tool pprof` or a continuous profiler. The profile records the binary's build ID, so
tools can add source lines from a matching unstripped build. Send the admin secret in
`X-Jazz-Admin-Secret`, or scrape it from the diagnostics listener with its token. The profile
covers memory the server allocates from Rust, not memory SQLite allocates internally.
With sampling off the route answers `404 Not Found`; other platforms answer `501 Not Implemented`.

The `--diagnostics-listen` and `--diagnostics-token` options are listed under [Your Own Server](/docs/setup/deployment/own-server).
