Jazz is a relational database with live queries, permissions and built-in collaboration. Run it yourself right next to your app on Vercel, Cloudflare or your own servers, scaling from zero to many shards. Use it from your backend, web and native clients, with local-first sync where you need offline.

<Callout type="info">
  Preview: this overview is being reworked for the server-first docs. The snippet below is still the
  client-side one; it will become schema + one policy + a user-scoped backend route + a client
  subscribing to the same query.
</Callout>

```ts
import { schema as s } from "jazz-tools";

// Define your schema
const schema = {
  todos: s.table(
    {
      title: s.string(),
      done: s.boolean(),
    },
    {},
  ),
};
const app = s.defineApp(schema);

// Write — instant, works offline
db.insert(app.todos, { title: "Ship it", done: false });

// Read — reactive, stays up to date across devices
db.subscribe(app.todos.where({ done: false }), (todos) => {
  console.log(todos);
});
```

Jazz works with React, Vue, Svelte, Solid, Expo/React Native, plain TypeScript, and Rust.
