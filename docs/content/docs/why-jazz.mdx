## For developers

- Why use a higher-abstraction-level DB at all? Live queries, permissions and merges instead of an API layer you write and maintain
- Serverless DBs and the tradeoff of early sharding
- Unsharded Jazz is MIT and free; when you'd need sharding and what it costs
- Server-first by default, local-first as an optimization where it pays off

## For decision-makers

- Custom code as a liability: less backend code to own
- Fewer systems and moving parts
- Runs in your own cloud: Vercel, Cloudflare, AWS, bare metal
- What you operate yourself on each platform, plus a cost calculator
- Licensing: MIT for unsharded Jazz, a license for sharded Jazz
