## Install

Create a project, then install the TypeScript package:

```bash title="Terminal"
pnpm add jazz-tools@alpha
```

For a Node.js runtime, install the native runtime package as well:

```bash title="Terminal"
pnpm add jazz-tools@alpha jazz-napi@alpha
```

<Callout type="warn" title="React Native and Expo are not supported at runtime">
  The React Native surface currently typechecks, but its persistent SQLite driver throws when
  opened. Do not ship a React Native or Expo application on this alpha runtime.
</Callout>

## Define a schema

Create `schema.ts` and export a typed app. The table handles are the inputs to queries and writes.

```ts title="schema.ts"
import { schema as s } from "jazz-tools";

const schema = {
  todos: s.table({
    title: s.string(),
    done: s.boolean().default(false),
    priority: s.int().default(0),
  }),
};

export const app = s.defineApp(schema);
```

Validate the schema and optional `permissions.ts`:

```bash title="Terminal"
pnpm dlx jazz-tools@alpha validate
```

## Open a database

Use `createDb` in plain TypeScript. `appId` isolates local storage and sync state. Add `serverUrl`
when this client should sync with an upstream server.

```ts title="src/main.ts"
import { BrowserAuthSecretStore, createDb } from "jazz-tools";
import { app } from "../schema.js";

const db = await createDb({
  appId: "your-app-id",
  secret: await BrowserAuthSecretStore.getOrCreateSecret({ appId: "your-app-id" }),
  // serverUrl: "https://your-sync-server.example",
});

const inserted = db.insert(app.todos, { title: "Ship the first screen" });
await inserted.wait({ tier: "local" });

const todos = await db.all(app.todos.orderBy("priority", "desc"));
```

Browser clients persist in OPFS by default. Set `driver: { type: "memory" }` for an ephemeral
standalone client. Add a `serverUrl` when that in-memory client should sync.

## React, Vue, Svelte, and Solid

The framework packages expose a client factory, a provider, and reactive query hooks. The same
schema and `Db` operations apply in every framework. See [Framework Patterns](/docs/reference/framework-patterns)
for the current framework-specific imports and [Queries](/docs/reading/queries) for `useAll`.

## Start sync

Use a `serverUrl` that identifies a Jazz serving node. Active queries are announced upstream and
matching current rows stream into the local replica. Writes are local immediately and are then
submitted upstream. See [How Sync Works](/docs/concepts/how-sync-works) for role, fate, and
durability semantics.
