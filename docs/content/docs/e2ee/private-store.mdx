The private store holds a device's keys: the keys that identify it in its account and the keys it holds
for each space. Jazz asks the store for a few operations and nothing more:

| Operation                                        | What it does                                                                                                                                                                           |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `load(scope, doc)`                               | The saved document and its revision, or `null`.                                                                                                                                        |
| `loadAll(scope, incarnation)`                    | Optionally reads all document names, bytes and revisions from one snapshot. Throws `PrivateStoreWipedError` if the scope is missing or its incarnation changed.                        |
| `openScope(scope)`                               | The scope's incarnation, a number fixed when the scope is made.                                                                                                                        |
| `save(scope, incarnation, doc, bytes, expected)` | Replaces a document if the scope and the document's revision are as expected, atomically; otherwise throws `PrivateStoreConflictError` or `PrivateStoreWipedError` and writes nothing. |
| `list(scope)`, `delete(scope)`                   | Names the documents of a scope, removes a scope.                                                                                                                                       |
| `protect(secret)`, `unprotect(blob)`             | Protects a secret at rest.                                                                                                                                                             |

Documents hold keys, so the store must keep them private: files readable only by the app's user, and
`protect` binding the device's private keys to the machine. A copied store whose protection travels
with it can answer a device-approval challenge as the original would, so `protect` should use a key
that does not leave the machine, such as one in the operating system's key store (Keychain, Credential
Manager, libsecret).

## A store to start from

Keep the files in a directory and the key that protects them in your key store. Give each directory
one owner. Use a single store instance for that directory, including across processes. Its queue
serialises the revision check and replacement within that instance. Document names must be non-empty.
Names starting with a dot are reserved for store metadata and temporary files.

A scope is active while its incarnation marker exists. Deletion removes that marker atomically
before cleaning up the documents. If cleanup is interrupted, reads ignore the orphaned documents
and opening the scope discards them before publishing a new marker. See the [private store contract](https://github.com/garden-co/jazz/blob/94cd8e1e45/packages/jazz-tools/src/encryption/private-store.ts#L22-L56).

Jazz uses `loadAll` at startup when the store provides it. Check the scope's incarnation and
read its documents in the same transaction or snapshot. The browser store does this in IndexedDB.
Stores that omit the method use individual reads. Native UniFFI callbacks use individual reads.

```ts
import { mkdir, readFile, readdir, rename, rm, unlink, writeFile } from "node:fs/promises";
import { createCipheriv, createDecipheriv, randomBytes } from "node:crypto";
import {
  PrivateStoreConflictError,
  PrivateStoreWipedError,
  type PrivateStore,
} from "jazz-tools/backend";

/** `machineKey` is 32 bytes from your operating system's key store. */
export function directoryStore(dir: string, machineKey: Buffer): PrivateStore {
  const at = (scope: string) => {
    if (!scope || scope === "." || scope === "..") throw new Error("Invalid scope name");
    return `${dir}/${encodeURIComponent(scope)}`;
  };
  const docPath = (scope: string, doc: string) => {
    if (!doc || doc.startsWith(".")) throw new Error("Invalid document name");
    return `${at(scope)}/${encodeURIComponent(doc)}`;
  };
  const marker = (scope: string) => `${at(scope)}/.incarnation`;
  const isMissing = (error: unknown) => (error as NodeJS.ErrnoException).code === "ENOENT";
  const incarnationOf = async (scope: string) => {
    try {
      return BigInt(await readFile(marker(scope), "utf8"));
    } catch (error) {
      if (isMissing(error)) return null;
      throw error;
    }
  };
  const read = async (scope: string, doc: string) => {
    try {
      const text = await readFile(docPath(scope, doc), "utf8");
      const { revision, bytes } = JSON.parse(text);
      return { revision: BigInt(revision), bytes: new Uint8Array(Buffer.from(bytes, "base64")) };
    } catch (error) {
      // Only a missing file means "absent"; any other error must not read as a new device.
      if (isMissing(error)) return null;
      throw error;
    }
  };
  let queue: Promise<unknown> = Promise.resolve();
  // One operation at a time: a save checks and replaces atomically.
  const serial = <T>(work: () => Promise<T>) => (queue = queue.then(work, work)) as Promise<T>;
  return {
    load: (scope, doc) =>
      serial(async () => ((await incarnationOf(scope)) === null ? null : read(scope, doc))),
    openScope: (scope) =>
      serial(async () => {
        const current = await incarnationOf(scope);
        if (current !== null) return current;

        await rm(at(scope), { recursive: true, force: true });
        await mkdir(at(scope), { recursive: true, mode: 0o700 });
        const incarnation = randomBytes(8).readBigUInt64BE() || 1n;
        const pending = `${marker(scope)}.tmp`;
        await writeFile(pending, incarnation.toString(), { mode: 0o600 });
        await rename(pending, marker(scope));
        return incarnation;
      }),
    save: (scope, incarnation, doc, bytes, expected) =>
      serial(async () => {
        if ((await incarnationOf(scope)) !== incarnation) throw new PrivateStoreWipedError();
        const current = await read(scope, doc);
        if ((current?.revision ?? null) !== expected) throw new PrivateStoreConflictError();
        const revision = (current?.revision ?? 0n) + 1n;
        const body = JSON.stringify({
          revision: revision.toString(),
          bytes: Buffer.from(bytes).toString("base64"),
        });
        const path = docPath(scope, doc);
        const pending = `${at(scope)}/.document.tmp`;
        await writeFile(pending, body, { mode: 0o600 });
        await rename(pending, path);
        return revision;
      }),
    list: (scope) =>
      serial(async () => {
        if ((await incarnationOf(scope)) === null) return [];
        return (await readdir(at(scope)))
          .filter((name) => !name.startsWith("."))
          .map(decodeURIComponent);
      }),
    delete: (scope) =>
      serial(async () => {
        await unlink(marker(scope)).catch((error) => {
          if (!isMissing(error)) throw error;
        });
        await rm(at(scope), { recursive: true, force: true });
      }),
    async protect(secret) {
      const iv = randomBytes(12);
      const cipher = createCipheriv("aes-256-gcm", machineKey, iv);
      const sealed = Buffer.concat([cipher.update(secret), cipher.final()]);
      return new Uint8Array(Buffer.concat([iv, cipher.getAuthTag(), sealed]));
    },
    async unprotect(blob) {
      const bytes = Buffer.from(blob);
      const decipher = createDecipheriv("aes-256-gcm", machineKey, bytes.subarray(0, 12));
      decipher.setAuthTag(bytes.subarray(12, 28));
      return new Uint8Array(Buffer.concat([decipher.update(bytes.subarray(28)), decipher.final()]));
    },
  };
}
```

For tests and sessions that keep nothing, `memoryPrivateStore()` is a store in memory that protects
nothing.

<Callout type="warn">
  `memoryPrivateStore()` is for tests only. Its `protect` returns the secret unchanged, and the
  device's keys are lost when the app restarts, so the device must be approved again. It is exported
  from `jazz-tools/react-native` and `jazz-tools/expo` for tests: don't ship it in an app.
</Callout>

Each store request crosses to the native runtime and back on a short timer, so a store call costs a few
milliseconds; keys are saved rarely, so this does not show in use. A store that does not answer a
request within 30 seconds fails that call with a store error.
