## The current schema is the contract

`schema.ts` defines the tables, columns, references, defaults, and merge strategies used by an
application. Jazz derives a content-addressed schema identity from this shape and validates every
query and mutation against it.

Validate before you deploy:

```bash title="Terminal"
pnpm dlx jazz-tools@alpha validate
```

Keep `schema.ts` and `permissions.ts` in source control and release the application build that uses
them as one unit. The alpha does not publish a mixed-schema interoperability contract, so test the
exact deployed schema and client/server versions together.

## Inspect the schema

Use the CLI to print the current schema identity or compiled structural representation:

```bash title="Terminal"
pnpm dlx jazz-tools@alpha schema hash
pnpm dlx jazz-tools@alpha schema export
```
