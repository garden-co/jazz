Validate your schema and permissions locally:

`pnpm dlx jazz-tools@alpha validate`

This validates `schema.ts` and `permissions.ts`, then compiles them into Jazz's
internal schema representation.

When Jazz reports a difference between the old and new schema hashes after changing `schema.ts`, and your app already has data, create a migration and deploy the updated app as described in [Migrations](/docs/schemas/migrations):

```bash
pnpm dlx jazz-tools@alpha migrations create <appId> --fromHash <fromHash> --toHash <toHash>
pnpm dlx jazz-tools@alpha deploy <appId>
```
