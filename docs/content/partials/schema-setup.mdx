Validate your schema and permissions locally:

`pnpm dlx jazz-tools@alpha validate`

This validates `schema.ts` and `permissions.ts`, then compiles them into Jazz's
internal schema representation.

When Jazz reports a difference between the old and new schema hashes after changing `schema.ts`, and your app already has data, create a migration as described in [Migrations](/docs/schemas/migrations), then restart your main backend (locally) or deploy it as usual: on start, `createJazz` publishes the new schema, permissions and migrations:

```bash
pnpm dlx jazz-tools@alpha migrations create <appId> --fromHash <fromHash> --toHash <toHash>
```
