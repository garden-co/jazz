## Install

```bash title="Terminal"
npm install jazz-tools
```

This installs Jazz 2, which is in [beta](/docs/operating/backups-and-upgrades#what-beta-means). Versions before 2.0 are
[Classic Jazz](https://classic.jazz.tools), which has a different API: projects on `jazz-tools` 0.x
and guides that use `co.map`, `CoValue` or `Group` are Classic.
