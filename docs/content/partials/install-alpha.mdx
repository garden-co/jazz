## Install

Jazz 2 is in alpha and published under npm's `alpha` tag, so install it with `@alpha`:

```bash title="Terminal"
npm install jazz-tools@alpha
```

npm's `latest` tag is still [Classic Jazz](https://classic.jazz.tools) (0.x), which has a different
API, so a plain `npm install jazz-tools` gets the wrong version. Jazz 2 leaves alpha soon, and
`latest` will move to it then.
