The most common column types in `jazz.app.json` are `"string"`, `"boolean"`, `"int"`, `"float"`, `"timestamp"`, `"bytes"`, `"uuid"`, `{ "array": "string" }`, `{ "enum": ["a", "b"] }`, `{ "json": true }`, and `{ "json": { …JSON Schema… } }`. Add `?` (`"string?"`) to make a column optional.

For the full TypeScript/SQL mapping table, see [Schemas: available column types](/docs/schemas/column-types).
