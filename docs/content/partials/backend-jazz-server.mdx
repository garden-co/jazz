**Run a Jazz server next to it.** A Rust or Go backend can't run Jazz's core in its own process yet,
so it keeps the data in a Jazz server you run beside it, with the standalone `jazz-tools` binary
(see [CLI](/docs/tooling/cli-and-mcp)). Make an app ID, choose two secrets, and start it:

```bash title="Terminal"
jazz-tools create app                       # prints a new app ID
jazz-tools server <app id> --port 1625 --data-dir ./data/jazz \
  --admin-secret "$JAZZ_ADMIN_SECRET" --backend-secret "$JAZZ_BACKEND_SECRET"
```

The server keeps the data in `--data-dir` (`--blobs` chooses where large values go). Keep it
reachable only from your backend: it trusts whoever holds the admin secret, and your users' clients
connect to your backend's `/jazz`, never to it. Point your backend at it with the server's URL
(`http://localhost:1625`), the app ID and both secrets. An existing app on
[Jazz Cloud (deprecated)](/docs/setup/deployment/jazz-cloud) works the same way, with its sync URL
and secrets.
