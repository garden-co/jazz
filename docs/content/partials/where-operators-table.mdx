Operator support by column type (TypeScript):

| Column kind       | Operators / shape                          |
| ----------------- | ------------------------------------------ |
| `id`              | `eq`, `ne`, `in`                           |
| `string`          | `eq`, `ne`, `contains`, `in`               |
| `boolean`         | `eq`, `ne`, `in`                           |
| `int` / `float`   | `eq`, `ne`, `gt`, `gte`, `lt`, `lte`, `in` |
| `timestamp`       | `eq`, `ne`, `gt`, `gte`, `lt`, `lte`, `in` |
| `bytes`           | `eq`, `ne`, `in`                           |
| `uuid` (required) | `eq`, `ne`, `in`                           |
| `uuid?`           | `eq`, `ne`, `in`, `isNull`                 |
| `enum`            | `eq`, `ne`, `in`                           |
| `array`           | `eq`, `contains`, `in`                     |
| `json`            | `eq`, `ne`, `in`                           |

Nullable columns with ordinary filter operators also support `isNull`. Required columns, `id`, and payload enums do not expose it.
