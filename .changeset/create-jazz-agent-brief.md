"create-jazz": patch
---

`npm create jazz` no longer scaffolds a starter. It fetches the Jazz agent brief from https://jazz.tools/agent-brief.md and prints it, so your coding agent can set Jazz up in your project, existing or empty, using the framework's own scaffolder and the live docs. The command asks no questions and writes no files. It no longer installs a bundled Jazz skill or provisions a Jazz Cloud app.
