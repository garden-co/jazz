Subscriptions can deliver a `string` or `bytes` column's changes as splices: name the columns in the `splices` query option and read them from `onUpdate(rows, { splices })`. On a range select the splices are relative to the selected window. Columns of other types, transformed columns, and range-selected columns that a computed field reads are refused as not supported yet. The React Native native relay ABI is now 4, so the JavaScript bundle and native build must match.
